# ระบบประเมินการปฏิบัติงานบุคลากรทางการศึกษา (Performance Evaluation System)

ระบบประเมินการปฏิบัติงานบุคลากรทางการศึกษา เป็นเว็บแอปพลิเคชันที่พัฒนาขึ้นด้วย PHP และ MySQL เพื่อใช้ในการบริหารจัดการ ประเมินผล และสรุปคะแนนการปฏิบัติงานของบุคลากรภายในสถานศึกษา ระบบถูกออกแบบมาให้ใช้งานง่าย รองรับการประเมินตามสายบังคับบัญชา (Top-Down) และการประเมินจากส่วนกลาง

## ✨ คุณสมบัติเด่น (Features)
- **ระบบแบ่งสิทธิ์การใช้งาน:** รองรับผู้ใช้งาน 3 ระดับ ได้แก่ ผู้ดูแลระบบ (Admin), กรรมการประเมิน (Evaluator), และบุคลากร/ผู้รับการประเมิน (Staff)
- **ปรับแต่งสถานศึกษาได้:** สามารถเปลี่ยนชื่อสถานศึกษา โลโก้ และโทนสีของระบบ (Theme) ได้จากหน้าตั้งค่า
- **การประเมินแบบยืดหยุ่น:** ตั้งค่าให้ประเมินโดยหัวหน้างานโดยตรง และ/หรือ กรรมการกลั่นกรองระดับแผนก/ส่วนกลาง
- **การจัดการรอบการประเมิน:** สามารถเปิด-ปิดรอบการประเมินได้ พร้อมกำหนดแบบฟอร์มคะแนนแบบไดนามิก
- **ระบบรายงาน (Reports):** สรุปคะแนนเป็นรายบุคคลและรายแผนก สามารถส่งออกข้อมูล (Export) เป็น Excel/CSV และพิมพ์รายงาน PDF ได้
- **การสำรองข้อมูล:** มีระบบ Backup ฐานข้อมูลและคะแนนในตัว

## 💻 ความต้องการของระบบ (System Requirements)
- PHP 7.4 หรือ 8.0 ขึ้นไป
- MySQL 5.7 หรือ MariaDB 10.x ขึ้นไป
- Web Server (Apache/Nginx) เช่น XAMPP, WAMP, หรือ LAMP Stack

## 🚀 วิธีการติดตั้ง (Installation Guide)

1. **ดาวน์โหลด Source Code**
   - นำไฟล์ทั้งหมดไปวางไว้ในโฟลเดอร์ Web Root ของคุณ (เช่น `htdocs` สำหรับ XAMPP หรือ `www` สำหรับ WAMP)
   - *ตัวอย่าง:* `C:\xampp\htdocs\npcjob_free`

2. **นำเข้าฐานข้อมูล (Import Database)**
   - เปิด phpMyAdmin หรือโปรแกรมจัดการฐานข้อมูลของคุณ
   - สร้างฐานข้อมูลใหม่ (เช่น ชื่อ `npcjob_db`)
   - เลือกเมนู **Import** แล้วอัปโหลดไฟล์ `npcjob_db.sql` (ไฟล์ฐานข้อมูลที่มีให้) เข้าสู่ระบบ

3. **ตั้งค่าการเชื่อมต่อฐานข้อมูล**
   - เปิดไฟล์ `config.php` ด้วย Text Editor
   - ค้นหาและแก้ไขบรรทัดต่อไปนี้ให้ตรงกับฐานข้อมูลของคุณ:
     ```php
     define('DB_HOST', 'localhost');
     define('DB_NAME', 'npcjob_db'); // เปลี่ยนเป็นชื่อฐานข้อมูลของคุณ
     define('DB_USER', 'root');      // ชื่อผู้ใช้ฐานข้อมูล
     define('DB_PASS', '');          // รหัสผ่านฐานข้อมูล (ถ้ามี)
     ```

4. **เข้าใช้งานระบบ**
   - เปิด Web Browser และพิมพ์ URL ของระบบ เช่น `http://localhost/npcjob_free`
   - ใช้บัญชีผู้ดูแลระบบเริ่มต้นในการเข้าสู่ระบบ:
     - **Username:** `admin`
     - **Password:** `admin`
   - *(แนะนำ: เมื่อเข้าสู่ระบบแล้ว ให้ไปที่เมนูจัดการผู้ใช้งานเพื่อเปลี่ยนรหัสผ่านทันทีเพื่อความปลอดภัย)*
